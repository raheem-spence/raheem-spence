## Currently Building

### Index
A course-based collaboration platform that helps students organize classes, share learning resources, and collaborate through shared notes.

Built with:
- **Backend**: Java, Spring Boot, Spring Security
- **Database**: PostgreSQL, Hibernate/JPA
- **Frontend**: HTML, CSS, JavaScript
- **Testing**: JUnit 5, Mockito

Features:
- Create and join courses to organize course-specific resources
- Create, view, edit, and delete notes within courses
- Enforce ownership-based permissions so note owners can edit or delete their notes while other course members have read-only access
- Persist users, courses, and notes in PostgreSQL
- Test backend service logic using JUnit 5 and Mockito
